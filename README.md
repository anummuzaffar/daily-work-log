# Daily Work Log

- Book view (gift-wrapped cover, opens to each day's tasks): https://anummuzaffar.github.io/daily-work-log/
- Dashboard with PDF / Excel reports: https://anummuzaffar.github.io/daily-work-log/dashboard.html

- Task data lives in [`data/tasks.json`](data/tasks.json) and is updated daily.
- Pick a period (today, this week, this month, or custom dates) and filter by status or project.
- **Download Excel report** saves an `.xlsx` with a Summary sheet and a Tasks sheet for the selected period.
